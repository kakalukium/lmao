study discrete math.

especially if you’re into computer science, software, algorithms, robotics, or ai.

calculus teaches you about continuous change.

discrete math teaches you how computation thinks.

• logic → propositions, predicates, proofs. the foundation of rigorous reasoning.

• sets → how objects are grouped, related, and manipulated.

• combinatorics → how many possibilities exist? how quickly does the search space explode?

• graph theory → nodes + edges. networks, maps, dependencies, routing, knowledge graphs.

• recurrence relations → understanding recursive processes and algorithm behavior.

• probability → reasoning when outcomes aren’t deterministic.

• number theory → modular arithmetic, primes, cryptography.

then suddenly a lot of computer science starts connecting.

• trees are graphs.

• databases use relations.

• compilers manipulate formal languages.

• path planning becomes graph search.

• cryptography becomes number theory.

• algorithm analysis becomes combinatorics.

discrete math is one of those subjects that quietly changes how you think.

you stop seeing code as syntax.

you start seeing the mathematical structures underneath it.
